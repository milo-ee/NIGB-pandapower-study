# Assumptions

This project is a simplified portfolio model and is not an exact representation of the full New Zealand transmission network.

Key assumptions:

- The model uses a simplified 5-bus network.
- Transmission line parameters are representative demo values.
- Load growth is simulated by scaling all active and reactive loads.
- The voltage operating limit is assumed to be 0.95 p.u. to 1.05 p.u.
- A line loading above 100% is treated as an overload.
- The shunt capacitor is modelled as capacitive reactive power injection.
- The model is designed for educational and portfolio demonstration purposes.

Original academic assignment files, submitted coursework, student ID information, PDFs, Excel templates, and confidential course material are not included.
